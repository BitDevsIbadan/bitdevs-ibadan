Below is a list of places to find interesting topics to discuss at BitDevs Ibadan. If you know others, open a pull request to add them.

### Mailing lists, newsletters, Q&A

- [bitcoindev mailing list](https://groups.google.com/g/bitcoindev)
- [Delving Bitcoin](https://delvingbitcoin.org/)
- [Bitcoin Optech](https://bitcoinops.org/)
- [Bitcoin Stack Exchange](https://bitcoin.stackexchange.com/)

### Git repositories

- [Bitcoin Core](https://github.com/bitcoin/bitcoin)
- [Core Lightning](https://github.com/ElementsProject/lightning)
- [Lightning Network Daemon](https://github.com/lightningnetwork/lnd)
- [Eclair](https://github.com/ACINQ/eclair)
- [rust-bitcoin](https://github.com/rust-bitcoin)
- [Lightning Dev Kit](https://github.com/lightningdevkit)
- [Bitcoin Dev Kit](https://github.com/bitcoindevkit)
- [Fedimint](https://github.com/fedimint)
